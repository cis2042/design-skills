# 预览与对照方法

当前参考实现见 `assets/device-preview/frontend/`，使用 React 共享状态与两套 Ant Design 组件库；已构建静态入口位于其上级。备份旧实现后再迁移。

先确认同一功能场景，再调整布局；Phone/Pad 不得通过隐藏功能制造能力差异。固定逻辑视口，外层缩放不得改变响应式断点。Portal 及组件浮层、主题样式必须指向对应 iframe 文档。

输入、枚举、开关和本地演示保存更新共享状态；独立模式则分开维护。密钥、文件内容、真实后端写入不进入共享数据。URL 仅包含导航状态。

先构建，再以静态 HTTP 服务验收 28 场景与两种主题，检查页面异常、资源缺失、横向溢出以及具体操作链路。复制到项目外仍须能启动。记录来源、版本锁文件与 SHA256；截图不替代动态验证，模拟流程不替代真实业务服务。
