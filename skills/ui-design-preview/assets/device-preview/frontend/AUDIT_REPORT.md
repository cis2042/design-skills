# 跨设备功能与布局复核

## 范围与证据
- 15 个设备预设（含折叠、展开与智能屏），29 个尺寸/方向组合。
- 28 个页面 + 7 类新建配置表单，浅深主题：2,030 个布局检查。
- 7 类能力配置 × 29 个组合 × 2 个主题：406 次新建、输入同步、保存与启停流程。
- 模型添加/删除、插件链接导入草稿、任务创建、消息发送 × 29 个组合：116 次流程（深色）。
- 另执行默认尺寸的 56 组页面/主题及模型获取、ZIP 预览、独立/联动模式等回归。

## 已修复
1. 禁用模型修改 ID 时，同步迁移禁用状态，避免被意外启用。
2. 删除模型时同时清理禁用记录，避免同名模型重新添加时继承旧状态。
3. 弹窗通过 portal 渲染到设备文档，补齐主按钮主题规则，统一手机与 Pad 主次操作层级。
4. 为弹窗按钮明确字号、最小高度和图文间距。

## 实测结果
matrix-audit.json：2030 cases，0 个横向溢出、弹窗/操作区越界或指定工具栏按钮高度异常。
action-matrix.json：406 cases 通过。
flow-matrix.json：116 cases 通过。
verify_model_state.py：禁用模型改名后两端状态保留。
verify_button_hierarchy.py：两端两种主题的弹窗主按钮实际背景色一致。
滚动检查验证内容末尾可达、操作区固定、滚动条隐藏。
代表性截图复核包含 iPhone SE 横屏与 Galaxy Z Fold 6 展开尺寸；截图工具直接调整 iframe，外部设备名称仍显示初始选择，实际尺寸以审计 JSON 为准。

## 边界
这是浏览器交互原型检查，不代表真机 WebKit、软键盘、安全区域、DPR 或业务后端验证。
2,030 组为布局检查，不等于每个组合都完成所有交互分支；操作覆盖范围见上方两个流程矩阵。
